How the project works

From browser strokes to a predicted digit

This project is a compact inference demo built around an MNIST-style handwritten digit classifier. What you draw is transformed into the same representation used during training.

1

Capture

The browser reads your drawing from the canvas or takes an uploaded image as input.

2

Preprocess

The backend converts the image to grayscale, resizes it to 28x28, normalizes pixel values, and inverts if needed.

3

Infer

The trained neural network consumes the flattened 784-value input and computes class logits for digits 0 to 9.

4

Explain

The UI shows both the processed image and the full probability chart so you can see why one digit won over the others.

What is happening mathematically?

Each dense layer learns useful stroke patterns such as loops, edges, angles, and relative placement. The last layer produces scores, and softmax turns those scores into probabilities.

Best input tips

  • Draw one digit at a time.
  • Keep the digit close to the center of the canvas.
  • Use thick, clear strokes and avoid extra marks.
How MNIST Digit Classification Works
The Classification Pipeline
  1. Input Preprocessing

    The image is converted to grayscale, resized to 28×28 pixels, and normalized to match the MNIST dataset format.

  2. Feature Extraction

    The neural network extracts meaningful features from the image through multiple layers of computation.

  3. Classification

    The final layer produces logits which are converted to probabilities using softmax activation. The highest probability indicates the predicted digit.

Key Neural Network Concepts
Dense Layers
Fully connected layers that learn patterns by adjusting weights between all neurons.
ReLU Activation
A non-linear function that helps the network learn complex patterns.
Softmax
Converts the final layer outputs into probabilities that sum to 1.
